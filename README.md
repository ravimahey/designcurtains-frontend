# Design Curtains & Blinds (Sydney) — Modern Website Redesign (Blue Palette Edition)

A luxury, high-converting digital redesign for **[Design Curtains & Blinds Sydney](https://www.designcurtains.com.au/)** (`designcurtains.com.au`), located at Castle Hill Homemaker Centre, Sydney NSW (Est. 1971).

---

## 🎨 New Fonts & Blue Palette System

### 1. Typography System
- **Display & Headings**: `Playfair Display` (Classic Editorial Luxury), `Cinzel` (Architectural Couture), or `Outfit` (Modern Executive).
- **Body & Interface**: `Outfit` paired with `Plus Jakarta Sans` for clean, high-legibility readability across all screens.
- **Dynamic Font Switcher**: Live switcher in the top bar allowing instant switching between `Playfair`, `Cinzel`, and `Outfit`.

### 2. Blue Color Palette
- **Deep Midnight Navy (`#0A0F1D` / `#0F172A`)**: Editorial topbars, hero accents, footer, and summary containers.
- **Royal Sapphire (`#1E40AF` / `#2563EB`)**: High-contrast primary call-to-action buttons, active tabs, and interactive slider toggles.
- **Sky Azure (`#38BDF8` / `#7DD3FC`)**: Radiant accents, highlight badges, and focus indicators.
- **Ice Blue & Slate (`#F0F6FF` / `#F8FAFC` / `#E0EDFE`)**: Clean, luxurious background cards, subtle borders, and pill tags.

---

## 🌟 Key Features

1. **Interactive Curtain Heading Style Visualizer**: Switch between S-Fold / Wave, Triple Pinch Pleat, Double Pinch Pleat, Inverted Box Pleat, and Pelmets with fabric fullness ratios, light stack, and Somfy motorisation compatibility.
2. **Instant Price & Yardage Estimator**: Real-time pricing calculations based on room size sliders, fabric grade, and Somfy motorisation toggle with 1-click booking prefill.
3. **Interactive Before / After Comparison Slider**: Users can drag to see a bare glass room transformed by floor-to-ceiling Belgian linen sheer drapes.
4. **European & Australian Fabric Showcase**: Opacity filters, texture profiles, and a **Complimentary 4-Swatch Sample Box Order Drawer** with free express Australian delivery.
5. **Castle Hill Homemaker Centre Showroom & Suburb Checker**: Interactive search covering the Hills District, North Shore, Eastern Suburbs, Western Sydney, and Northern Beaches.
6. **Consultation Booking Modal**: Step-by-step in-home laser measure or showroom walkthrough booking with confetti celebration.
7. **Mobile Bottom Action Pill**: Floating click-to-call and quick booking bar for smartphones.

## 🚀 Running the Project

```bash
# Navigate to the project directory
cd designcurtains.com-frontend

# Start development server
pnpm run dev

# Build production bundle
pnpm run build

# Preview production build
pnpm run preview
```
